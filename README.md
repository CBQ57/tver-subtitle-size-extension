# TVer 字幕サイズ

TVerの字幕を読みやすくする、パソコンの **Chrome・Edge用** 拡張機能です（非公式）。

- 字幕の大きさを **10〜200％** に変更
- **標準／背景なし／黒背景＋黄色文字** をワンクリックで切り替え

## インストール

1. [ダウンロードページ](https://github.com/CBQ57/tver-subtitle-size/releases/latest)の **Assets** から、`tver-subtitle-size-v1.1.4.zip` をダウンロードします。
2. ZIPを右クリックし、**「すべて展開」** を選びます。
3. ブラウザのアドレスバーに `chrome://extensions` と入力します。Edgeの場合は `edge://extensions` です。
4. **「デベロッパーモード」** をオンにします。Edgeでは「開発者モード」です。
5. **「パッケージ化されていない拡張機能を読み込む」** を押し、展開した中の **extension** フォルダーを選びます。Edgeでは「展開して読み込み」を押します。

読み込んだフォルダーは削除せず、そのまま置いておいてください。

## 使い方

1. TVerのページを再読み込みし、字幕対応の番組で **CC（字幕）をオン** にします。
2. ブラウザ右上の **拡張機能（パズルのアイコン）→「TVer 字幕サイズ」** を開きます。
3. スライダーで大きさを、「Aa」ボタンで背景・文字色を選びます。設定は自動保存されます。

元に戻すには **「標準の100％に戻す」** と、左端の **「Aa」** を押してください。

※ 映像に最初から入っているテロップは変更できません。
