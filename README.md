# TVer 字幕サイズ（非公式）

デスクトップ版Chrome／Edge向けのManifest V3拡張機能です。TVerのCC字幕の表示倍率だけを10〜200％（5％刻み）で変更します。ページ、動画、操作ボタンの大きさは変更しません。背景・文字色も切り替えられます。

## インストール

1. ZIPの場合は、先にすべて展開します。
2. Chromeではアドレスバーに `chrome://extensions`、Edgeでは `edge://extensions` と入力します。
3. 「デベロッパーモード」（Edgeでは「開発者モード」）をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」（Edgeでは「展開して読み込み」）をクリックし、このフォルダー内の **extension** フォルダーを選びます。`manifest.json` が直下にあるフォルダーです。
5. TVerを開いていた場合は、一度ページを再読み込みします。
6. 字幕対応番組を再生し、TVerプレイヤーの **CCをオン** にします。
7. ツールバーの拡張機能メニューから「TVer 字幕サイズ」を開き、倍率を調整します。ピン留めすると便利です。

初期値は100％です。設定はこのブラウザに自動保存され、次回の視聴や別のTVerタブにも適用されます。「サイズ変更を有効にする」をオフにすると字幕サイズが標準に戻ります。

## 背景・文字色（v1.1.4）

操作画面の「背景・文字色」に並ぶ3つの「Aa」タイルから、1クリックで変更できます。選択中の配色にはオレンジの枠を表示し、透明背景のタイルには斜線を付けています。大きな表示例は追加していません。ポップアップのロゴは拡張機能と同じ水色のアイコン画像です。

- 標準：TVer本来の背景と文字色。
- 背景なし：字幕の背景を透明にし、元の文字色を維持。
- 黒背景＋黄色文字：文字の背後を不透明な黒（#000000）、文字を黄色（#FFFF00）に変更。

字幕サイズとは独立した設定です。100％やサイズ変更オフでも配色は適用されます。「標準の100％に戻す」はサイズだけを戻します。配色を元に戻す場合は「標準」を選びます。設定は自動保存され、字幕が切り替わっても維持されます。旧版からの更新時は標準配色になります。

この追加機能は実際のTVerの字幕構造を再現したローカルテストで確認しています。実番組上での配色変更は未検証です。

## 対応範囲と制限

- TVerのVideo.jsプレイヤーでHTMLとして表示されるCC字幕が対象です。
- 映像に焼き込まれたテロップ、字幕のない番組、画像・Canvas字幕、ブラウザ独自の字幕、別ドメインの埋め込みプレイヤー、ピクチャーインピクチャーには対応しません。
- TVerが各字幕行に指定する元の文字サイズを基準に、文字サイズ自体を変更します。行のブロック配置、文字内容、色、明示的な改行を保持します。背景と行間は文字サイズに追従し、下端を基準に字幕全体の高さを調整します。
- 大きい倍率では長文の端が切れたり、複数の字幕が重なる場合があります。その場合は倍率を下げてください。
- プレイヤーが全画面切り替えやリサイズで元の文字サイズを更新すると、その変更を監視して倍率を再適用します。
- TVerのプレイヤー構造変更により動かなくなる可能性があります。
- TVer公式とは無関係です。ストア公開・ブラウザへのインストールは行っていません。

## 権限・プライバシー

権限は設定保存用の `storage` と `https://tver.jp/*`、`https://www.tver.jp/*` へのコンテンツスクリプト適用のみです。外部への通信、視聴情報の収集、動画の取得はしません。サーバーやビルド、npmのインストールは不要です。

## v1.0.5の修正と検証

実際に再生中のChromeのTVerページを読み取り、字幕が `.vjs-text-track-cue` 内の複数の `.vjs-text-track-cue-line` に分かれていることを確認しました。v1.0.4の `display: inline-block` 指定が2行を横並びに変えていました。従来の1行だけのテストでは見逃していた不具合です。

新版は `display` や `scale` を変更せず、各行のインライン指定の元フォントサイズから倍率を計算します。元のfont-sizeは書き換えず、拡張機能専用CSS変数を設定します。100％または無効化で変数・属性を除去します。bottomで配置される字幕の固定高さは、変更後の複数行の自然な高さに追従させます。

実際のDOM構造と同じ2行のテストで、旧版の不具合を再現し、10・50・80・100・150・200％、行間、中央揃え、プレイヤー再生成、元フォントサイズの変更、100％への完全復元を検証しました。通常幅から1920pxまでのサイズ変更を含みます。Chromeの接続経由でFullscreen APIを呼ぶ操作は「not granted」となり、実際の全画面切り替えは今回未検証です。実番組でも75％設定で2行が縦に並び、文字サイズと中央揃えを確認しています。実際の全画面表示は未検証です。

テスト実行：Node.jsがある環境で `node tests/server.cjs` を実行し、`http://127.0.0.1:8137` を開きます。テスト用のChromeストレージアダプターを使用します。テストコードは配布用extensionフォルダーに含まれません。

更新時はファイルを置き換え、拡張機能管理画面の「再読み込み」を押した後、TVerページも必ず再読み込みしてください。古い版のCSSを取り除くために必要です。
